# Banking System in Java

Console application developed in Java to practice programming fundamentals and Object-Oriented Programming through a simple banking flow.

## Features

- Check account balance
- Receive funds
- Transfer funds
- Navigate through an interactive terminal menu

## Concepts Practiced

- Classes and objects
- Methods
- Conditional statements
- Loops
- User input
- Basic validation
- Object-Oriented Programming

## Technologies

- Java

## How to Run

1. Clone the repository.
2. Open the project in an IDE with Java support.
3. Run the main class.
4. Use the terminal menu to interact with the application.

## Purpose

The project was created as a study exercise to practice Java while modeling basic banking operations in a small console application.
